CHANNEL OWNER TOOL

A publishing workflow
for Upgrade Lab Gaming.

An owner-operated tool that renders original vehicle game simulations, uploads approved videos to the channel, and schedules their publication through the YouTube Data API.

Visit the YouTube channel
01 / CREATE

Render a challenge

Code creates animated vehicle tests with on-screen measurements, sound, and a result. Each approved episode has its own title, description, and hashtags.

02 / AUTHORIZE

Confirm the channel

The owner authorizes the tool through Google OAuth. The uploader checks the connected channel identity before sending the approved batch.

03 / SCHEDULE

Publish on a schedule

Videos are uploaded with an owner-selected publication time. Local records track successful uploads, and the owner's Telegram bot can report their progress.

How Google access is used

The tool uses youtube.upload to upload videos and set their publishing details. It uses youtube.readonly to identify the authorized channel. Authorization credentials and publishing records are stored in the operator's VPS account.

This website documents the channel owner's publishing tool. Google authorization takes place through the uploader's local authorization flow.
