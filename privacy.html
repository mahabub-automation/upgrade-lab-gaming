UPGRADE LAB GAMING

Privacy policy

Effective November 11, 2026

This policy describes the owner-operated Upgrade Lab Gaming publishing tool and its informational website. The channel operator maintains the tool on a VPS and controls its Google authorization and publishing configuration.

Information the tool handles

  • Channel identity. The authorized channel's ID and name are read to confirm the upload destination.
  • Publishing content. The tool processes the operator's video files, titles, descriptions, audience settings, visibility choices, and planned publication times.
  • Authorization information. Google OAuth access and refresh tokens allow the configured uploader to act for the authorized channel.
  • Operational records. Video IDs, upload receipts, file hashes, timestamps, queue state, and service logs support scheduling, duplicate prevention, and troubleshooting.

Why Google permissions are requested

The youtube.upload permission is used to upload approved videos and attach their publishing settings. The youtube.readonly permission is used to identify the channel connected to the uploader.

Google API data is used for the channel publishing workflow and its operational support. The operator follows the Google API Services User Data Policy, including its Limited Use requirements, when using or transferring information received from Google APIs.

Storage and retention

Authorization information, video files, queue metadata, upload receipts, and logs are stored in the operator-controlled VPS account. OAuth state files are written with owner-only file permissions. The operator maintains access to the server and controls retention and deletion.

Upload receipts are retained to recognize previously completed transfers. The operator can remove local data when it is no longer required and can clear authorization files when decommissioning the tool. Data sent to YouTube remains subject to the owner's YouTube settings and Google's policies.

Service providers and notifications

  • Google and YouTube. Google handles OAuth authorization. YouTube receives the selected video file and publishing metadata.
  • VPS hosting. The configured server hosts the processing workflow and its local files.
  • Telegram. If the owner's bot notifications are configured, Telegram receives video titles, links, publication times, and operational summaries for delivery to the configured owner chat.
  • GitHub Pages. GitHub hosts this informational website. GitHub documents that it logs visitors' IP addresses for security purposes in its GitHub Pages documentation and privacy statement.

Control access and delete data

The channel owner can stop the publishing service, remove local authorization and operational data, and revoke the application's Google access through Google Account permissions. Revoking access prevents future authorized API requests. Existing videos can be managed or deleted through YouTube Studio.

Contact and updates

For support or privacy requests, use the project's GitHub issues. Provide a general description of the request and keep credentials and account-specific details in your own system.

The operator updates this policy when the publishing workflow or its data practices change. The effective date appears at the top of this page.
